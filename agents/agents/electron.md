# Electron Development

When building or modifying Electron applications, **always load the `electron` skill** (`/agents/skills/electron/SKILL.md`) for guidance.

The skill covers:
- Main process, renderer process, and preload scripts
- IPC communication between processes
- BrowserWindow, Menu, Tray, and other native APIs
- Packaging, security best practices, and cross-platform development

Use the skill when: creating desktop apps, implementing IPC, managing windows, adding native features (menus, tray icons), or packaging/distributing Electron apps.
